
## 🔹 Desafio 2: Verificador de Palíndromos

> Verifica se uma palavra ou frase é um palíndromo (igual de trás para frente).

### ✅ Funcionalidades:
- Campo de texto para digitar a palavra
- Botão "Verificar"
- Mostra o resultado na tela
- Ignora espaços e letras maiúsculas

📷 **Exemplo:**

- Entrada: arara 
- Resultado: É um palíndromo!
