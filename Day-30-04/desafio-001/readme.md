# 🚀 Desafios Iniciais em JavaScript

Este repositório contém **3 desafios fáceis** desenvolvidos em **JavaScript puro**, ideais para quem está começando no desenvolvimento web e quer praticar **eventos, lógica e manipulação do DOM**.

---

## 📁 Estrutura dos Projetos

Cada desafio possui:
- HTML (`index.html`)
- CSS (`style.css`)
- JavaScript (`script.js`)

Organize-os em pastas separadas para testar localmente no navegador.

---

## 🔹 Desafio 1: Contador de Cliques

> Um botão que conta quantas vezes foi clicado.

### ✅ Funcionalidades:
- Botão "Clique aqui"
- Contador que aumenta a cada clique
- Atualiza o texto dinamicamente

📷 **Exemplo:**

- Você clicou 0 vezes.
