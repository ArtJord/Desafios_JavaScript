# 🧠 Desafios Aleatórios em JavaScript

Bem-vindo ao repositório! 👋  
Aqui você encontrará uma coleção de **desafios simples e aleatórios** que estou desenvolvendo para **praticar lógica de programação, reforçar conceitos de JavaScript** e me manter em constante aprendizado.

---

## 🎯 Objetivo

O objetivo deste projeto é:
- Treinar **JavaScript puro (Vanilla JS)**
- Melhorar minha **lógica de programação**
- Explorar **manipulação do DOM**
- Trabalhar com eventos, condições, funções e interações com o usuário
- Compartilhar ideias e soluções com a comunidade

---

## 📁 Desafios até agora

### 🔹 Desafio 1: Contador de Cliques
- Um botão que conta quantas vezes foi clicado.

### 🔹 Desafio 2: Verificador de Palíndromos
- Verifica se uma palavra ou frase é um palíndromo.

### 🔹 Desafio 3: Mudar Cor de Fundo Aleatoriamente
- Muda a cor de fundo da página para uma cor aleatória ao clicar no botão.
